# CV Redactor - Standalone Executable

## 🎯 What is this?

A Windows executable that removes all personal information from CVs/resumes. No installation, no Python, no internet needed.

## ⚡ Quick Start

```bash
# 1. Put your CVs in a folder
# 2. Run this command:
CVRedactor.exe your_cvs\ output\

# Done! Anonymized CVs are in output\
```

## 📦 What You Get

- **File**: `CVRedactor.exe` (371 MB)
- **Removes**: Names, emails, phones, addresses
- **Keeps**: Skills, experience, education
- **Works**: Offline, no installation needed

## 🚀 Usage Examples

### Process CVs
```bash
CVRedactor.exe resume\ output\
```

### Add Configuration
```bash
CVRedactor.exe add-city "Boston"
CVRedactor.exe add-term "python"
```

### View Configuration
```bash
CVRedactor.exe list-config
```
